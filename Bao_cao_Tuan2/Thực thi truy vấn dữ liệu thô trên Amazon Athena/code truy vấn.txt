Chạy truy vấn cơ bản (xem 10 dòng đầu):
SELECT * FROM sales LIMIT 10;

Chạy thêm các truy vấn phân tích nghiệp vụ trên CSV:
Truy vấn 1: Tổng doanh thu theo thành phố
SELECT 
    customer_city, 
    COUNT(order_id) AS total_orders,
    SUM(quantity * unit_price) AS total_revenue
FROM sales
GROUP BY customer_city
ORDER BY total_revenue DESC;

truy vấn 2: Thống kê số lượng bán theo danh mục
SQL
SELECT 
    category, 
    SUM(quantity) AS total_quantity_sold
FROM sales
GROUP BY category
ORDER BY total_quantity_sold DESC;
